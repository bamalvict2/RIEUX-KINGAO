👑 KINGDOMAINE — Gestion des clés SSH

KINGDOMAINE est un système de gestion cryptographique basé sur deux types de clés SSH : la SOUPLE et la RIGIDE. Il garantit une compatibilité totale avec les environnements FIPS tout en offrant flexibilité et performance.

🟩 1. KINGSECURE — La SOUPLE

KINGSECURE est la clé adaptative du royaume. Elle change automatiquement selon l’état du système.

🔧 Comportement

  • FIPS activé → RSA 4096 (conforme FIPS)
  • FIPS désactivé → Ed25519 (rapide, moderne)

🎯 Objectif

  • Flexibilité
  • Performance
  • Adaptation automatique

📁 Emplacement

~/.ssh/KINGSECURE

🧠 Résumé

SOUPLE Suit les règles du système. Change quand FIPS change.

🟥 2. KING‑PRO — La RIGIDE

KING‑PRO est la clé professionnelle, invariable, toujours conforme FIPS.

🔧 Caractéristiques

  • Toujours RSA 4096
  • Toujours conforme FIPS
  • Ne dépend jamais du système
  • Ne change jamais une fois créée

🎯 Objectif

  • Production
  • GitHub
  • Bastions
  • Serveurs
  • Environnements réglementés

📁 Emplacement

~/.ssh/KING-PRO

🧠 Résumé

RIGIDE Stable. Prévisible. Conforme. Ne casse jamais.

🔐 3. Pourquoi deux clés ?

Parce que KINGDOMAINE combine :

  • la souplesse (KINGSECURE)
  • la rigidité (KING‑PRO)
  • la conformité FIPS
  • la performance

La sécurité doit être flexible quand c’est possible, rigide quand c’est nécessaire.

🧩 4. Désactivation FIPS

Grâce à KING‑PRO, tu peux désactiver FIPS sans casser SSH.

  • KING‑PRO continue de fonctionner (RSA 4096)
  • KINGSECURE bascule automatiquement en Ed25519
  • Aucun accès n’est perdu

Commande utilisée

fips-mode-setup --disable

🧪 5. Vérifications intégrées

✔ Vérification FIPS système

/proc/sys/crypto/fips_enabled

✔ Vérification KING‑PRO

  • RSA
  • 4096 bits
  • Conforme FIPS

✔ Vérification des clés publiques

ls ~/.ssh/*.pub

🛠️ 6. Fonctions principales

  • Générer clé standard
  • Générer KINGSECURE (SOUPLE)
  • Générer KING‑PRO (RIGIDE)
  • Vérifier KING‑PRO (FIPS)
  • Tester SSH GitHub
  • Désactiver FIPS
  • Afficher clé publique

🧠 7. Philosophie KINGDOMAINE

La sécurité doit être flexible quand c’est possible, rigide quand c’est nécessaire.

KINGSECURE = flexibilité
KING‑PRO = rigidité
KINGDOMAINE = harmonie entre les deux

🚀 8. Conclusion

KINGDOMAINE te donne un système cryptographique :

  • souple pour le quotidien
  • rigide pour la production
  • compatible FIPS
  • automatique et intelligent
  • stable et résilient
