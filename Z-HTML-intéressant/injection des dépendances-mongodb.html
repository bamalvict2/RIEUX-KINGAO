Organigramme — Injection de dépendances MongoDB
1. docker-compose (variables d’environnement)
Mongo__ConnectionString=mongodb://solaize-mongo:27017 Mongo__Database=SolaizeDb Mongo__Collection=Items
→ Prioritaires sur appsettings.json
⬇️
2. appsettings.json (valeurs par défaut)
"Mongo": { "ConnectionString": "mongodb://solaize-mongo:27017", "Database": "SolaizeDb", "Collection": "Items" }
→ Utilisé si aucune variable d’environnement ne remplace
⬇️
3. Program.cs — Binding de MongoSettings
builder.Services.Configure<MongoSettings>( builder.Configuration.GetSection("Mongo") );
→ ASP.NET Core crée un objet MongoSettings
⬇️
4. Program.cs — Création du MongoClient
builder.Services.AddSingleton<IMongoClient>(sp => { var settings = sp.GetRequiredService<IOptions<MongoSettings>>().Value; return new MongoClient(settings.ConnectionString); });
→ Un seul client MongoDB pour toute l’application
⬇️
5. Program.cs — Enregistrement du ItemService
builder.Services.AddScoped<ItemService>();
→ Un ItemService par requête HTTP
⬇️
6. ItemService — Injection automatique
public ItemService(IMongoClient client, IOptions<MongoSettings> options)
→ ASP.NET Core fournit automatiquement IMongoClient + MongoSettings
⬇️
7. ItemService — Construction de la collection
var settings = options.Value; var db = client.GetDatabase(settings.Database); _items = db.GetCollection<Item>(settings.Collection);
→ _items est prêt pour le CRUD MongoDB
