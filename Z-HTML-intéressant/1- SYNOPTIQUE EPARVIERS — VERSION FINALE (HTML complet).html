Relation entre PRJ1 et PRJ2

PRJ1 = cockpit local portable pour :
  - développement
  - démonstration
  - labo
  - monitoring interne
  - fonctionnement offline (SSD T3)

PRJ2 = architecture externe pour :
  - accès mobile (MAUI)
  - accès distant
  - scalabilité
  - production
  - cloud / Kubernetes

Les deux projets :
  - partagent la même logique métier
  - utilisent la même API (structure)
  - peuvent évoluer en parallèle
  - ne se remplacent pas : ils se complètent
