SDK Solaize – Mode HTTP Only

Cette documentation présente la version SDK de la stack Solaize : 100% HTTP, sans Certbot, sans Let’s Encrypt, sans HTTPS, totalement portable et reproductible.

docker-compose.yaml – Version SDK

Voici la version complète du compose SDK, propre, stable et portable :

version: "3.9"

services:

  solaize-api:
    build:
      context: ./Solaize-Api
      dockerfile: dockerfile
    container_name: solaize-api
    expose:
      - "8080"
    networks:
      - solaize-net
    restart: always
    environment:
      - ASPNETCORE_URLS=http://0.0.0.0:8080

  solaize-blazor-server:
    build:
      context: ./Solaize-Blazor-Server
      dockerfile: Dockerfile
    container_name: solaize-blazor-server
    expose:
      - "7000"
    networks:
      - solaize-net
    environment:
      - ASPNETCORE_URLS=http://0.0.0.0:7000
    depends_on:
      solaize-api:
        condition: service_healthy
      solaize-mongo:
        condition: service_started

  solaize-mongo:
    image: mongo:7.0
    container_name: solaize-mongo
    expose:
      - "27017"
    volumes:
      - ./mongo_data:/data/db
    networks:
      - solaize-net
    restart: always

  prometheus:
    image: prom/prometheus:latest
    container_name: prometheus
    expose:
      - "9090"
    networks:
      - solaize-net
    restart: always

  grafana:
    image: grafana/grafana:latest
    container_name: grafana
    expose:
      - "3000"
    networks:
      - solaize-net
    restart: always

  nginx:
    image: nginx:latest
    container_name: nginx
    ports:
      - "8080:80"
    volumes:
      - ./nginx.conf:/etc/nginx/nginx.conf:ro
    networks:
      - solaize-net
    restart: always
    depends_on:
      solaize-blazor-server:
        condition: service_started
      solaize-api:
        condition: service_started
      grafana:
        condition: service_started
      prometheus:
        condition: service_started

networks:
  solaize-net:
    driver: bridge

nginx.conf – Reverse Proxy SDK (HTTP Only)

Version propre, sans HTTPS, sans Certbot, sans Let’s Encrypt.

user nginx;
worker_processes auto;

events {
    worker_connections 1024;
}

http {
    include       /etc/nginx/mime.types;
    default_type  application/octet-stream;

    sendfile on;
    keepalive_timeout 65;

    gzip on;

    server {
        listen 80;
        server_name _;

        location / {
            proxy_pass http://solaize-blazor-server:7000/;
            proxy_http_version 1.1;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection "upgrade";
            proxy_set_header Host $host;
        }

        location /api/ {
            proxy_pass http://solaize-api:8080/;
        }

        location /grafana/ {
            proxy_pass http://grafana:3000/;
        }

        location /prometheus/ {
            proxy_pass http://prometheus:9090/;
        }
    }
}

Pourquoi supprimer HTTPS, Certbot et Let’s Encrypt ?

  • Le SDK doit être portable : SSD, Android, offline.
  • Certbot nécessite un domaine réel → impossible en local.
  • Let’s Encrypt impose des validations DNS/HTTP → inutilisable hors-ligne.
  • Les certificats expirent → plantage Nginx → restart loop.
  • Le mode SDK doit être simple, stable, reproductible.

Résumé final

Le SDK Solaize fonctionne désormais en HTTP only, sans aucune dépendance externe, parfaitement portable et stable.

  • Un seul réseau : solaize-net
  • Un seul port exposé : 8080
  • Nginx reverse proxy propre
  • Stack complète : API, Blazor, Mongo, Grafana, Prometheus
  • Prêt pour Docker Hub, T3/T7, Android
