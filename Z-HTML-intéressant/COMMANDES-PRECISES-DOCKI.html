Workflow Docker - Projet EPARVIER

  1. Ouvrir un terminal.
  2. Aller dans le dossier racine du projet : 
    cd /chemin/vers/EPARVIER
  3. Builder l’image de l’API : 
    docker build -t solaizeapi -f SolaizeApi/Dockerfile .
  4. Builder l’image du Blazor : 
    docker build -t blazor -f SolaizeCockpit/Dockerfile .
  5. Vérifier les images : 
    docker images
  6. Lancer les conteneurs : 
    docker compose up -d
  7. Vérifier les conteneurs : 
    docker ps
  8. Accéder à l’API sur http://localhost:5010
  9. Accéder à Blazor sur http://localhost:5110
  10. Arrêter l’infrastructure : 
    docker compose down
