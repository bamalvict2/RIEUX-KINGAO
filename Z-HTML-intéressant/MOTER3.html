2️⃣ Cycle détaillé : démarrage → fonctionnement → surveillance → exposition

Temps 1 — Démarrage (Admission)

  • DuckDNS pointe vers ton IP publique.
  • Cloudflare Tunnel est up et attaché à ton domaine.
  • Le trafic extérieur peut atteindre ton tunnel.

Temps 2 — Fonctionnement (Compression)

  • Compose EPARVIER lancé : MongoDB, API C#, Blazor démarrent.
  • Les ports internes (5010, 5110, 27017…) sont ouverts.

Temps 3 — Surveillance (Explosion)

  • Compose MONITORING lancé : Prometheus, exporters, Blackbox démarrent.
  • Prometheus scrappe API, Mongo, Node, cAdvisor, Blackbox.
  • Blackbox appelle l’API via l’URL publique (Tunnel + DNS).

Temps 4 — Exposition (Échappement)

  • Grafana expose les dashboards.
  • Cloudflare Tunnel expose cockpit/API vers Internet.
