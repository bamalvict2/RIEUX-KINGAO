Guide Complet : Création et Vérification d’une Clé SSH GitHub (Version Moderne)

1. Générer une clé SSH moderne (ed25519)

Commande recommandée par GitHub :

ssh-keygen -t ed25519 -C "votre_email_github"

Valider le chemin par défaut, puis entrer une passphrase.

2. Ajouter la clé à l’agent SSH

ssh-add ~/.ssh/id_ed25519

Vérifier que la clé est bien chargée :

ssh-add -l

3. Ajouter la clé publique à GitHub

Afficher la clé publique :

cat ~/.ssh/id_ed25519.pub

Copier → GitHub → Settings → SSH and GPG keys → New SSH key

4. Configurer le fichier ~/.ssh/config

Configuration recommandée (port 443 pour contourner les blocages réseau) :

Host github.com
    HostName ssh.github.com
    User git
    Port 443
    IdentityFile ~/.ssh/id_ed25519
    IdentitiesOnly yes

5. Tester la connexion SSH

ssh -T git@github.com

Réponse attendue :

Hi <username>! You've successfully authenticated...

6. Vérifier les remotes Git

git remote -v

7. Pousser une branche vers GitHub

git push -u origin nom_de_branche
