Mémo — Tailscale & Traversée de NAT

Comprendre comment ton G20 parle à KING‑AO même derrière des box et de la 4G.

Vue cockpit

NAT classique (box / routeur)

Rôle : traduire les IP locales pour sortir sur Internet, et bloquer les connexions entrantes.

  • Donne une IP locale (192.168.x.x, 10.x.x.x).
  • Traduit cette IP pour accéder à Internet.
  • Bloque les connexions entrantes par défaut.
  • Oblige à ouvrir des ports (port forwarding) → surface d’attaque.

Tailscale (NAT moderne + VPN mesh)

Rôle : créer un réseau privé mondial entre tes appareils, en traversant les NAT automatiquement.

  • Donne une IP privée Tailscale à chaque appareil (ex : 100.84.x.x, 100.116.x.x).
  • Relie tes appareils comme s’ils étaient dans le même LAN.
  • Traverse les NAT sans ouvrir de ports.
  • Chiffre tout le trafic entre les appareils.
En une phrase : Tailscale remplace le port forwarding par un LAN privé chiffré, qui traverse les NAT automatiquement.

Pipeline Tailscale pour traverser les NAT

Étapes en cascade

1. Hole punching

Les deux appareils (G20, KING‑AO) envoient des paquets vers Tailscale pour ouvrir une fenêtre temporaire dans chaque NAT.

Tailscale leur dit ensuite : « envoyez-vous des paquets directement à travers ces fenêtres ». Les NAT voient des paquets attendus → ils les laissent passer.

2. STUN

Tailscale utilise STUN pour découvrir :

  • Ton IP publique.
  • Le port que ton NAT a ouvert.
  • Le type de NAT (symétrique, restrictif, etc.).

STUN sert à comprendre comment percer ton NAT.

3. DERP (relai sécurisé)

Si le NAT est trop strict (certains opérateurs mobiles, hotspots), Tailscale utilise un serveur DERP comme relai chiffré.

  • G20 → envoie les paquets à DERP.
  • KING‑AO → envoie les paquets à DERP.
  • DERP relie les deux flux de manière sécurisée.
1
Tailscale tente le hole punching (connexion directe).
2
Il utilise STUN pour comprendre ton NAT et ajuster la stratégie.
3
Si nécessaire, il bascule sur DERP pour garantir la connexion.
Résultat : ton G20 peut parler à KING‑AO, même en 4G derrière des box, comme s’ils étaient dans le même réseau local.
