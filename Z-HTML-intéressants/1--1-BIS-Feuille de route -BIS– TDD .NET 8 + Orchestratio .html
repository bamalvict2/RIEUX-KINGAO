6. Roadmap Cloudflare Tunnel – KINGDOMAINE / EPARVIER

Phase 1 — Mise en place (VALIDÉE)

Objectif : rendre EPARVIER accessible en HTTPS depuis l’extérieur, sans ports ouverts.

  • Migration du domaine vers Cloudflare (DNS).
  • Installation de cloudflared dans la VM Ubuntu.
  • Création du tunnel sortant sécurisé.
  • Configuration du fichier config.yml.
  • Intégration avec Nginx (port 4443).
  • Mise en service du tunnel Cloudflare.
  • Validation de l’accès externe via https://eparvier.mondomaine.com.

Statut : ✔ Terminé, stable, validé.
