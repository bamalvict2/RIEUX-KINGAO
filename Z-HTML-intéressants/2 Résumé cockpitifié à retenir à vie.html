Résumé cockpitifié – qui décide quoi ?

Mongo est la source de vérité. C# et les DTO s’alignent sur lui, pas l’inverse.

Niveau Qui décide ? Rôle
MongoDB
Source de vérité 		✔ Le patron Génère l’ID, stocke, met à jour, supprime les documents.
Driver C# (MongoDB.Driver)
Interprète 		✔ L’interprète Convertit entre C# et BSON, parle le langage de Mongo.
Modèle C# (Item)
Contrat interne 		✔ Le contrat interne Décrit comment mapper les documents Mongo dans le code.
DTO (ItemCreateDto, ItemDto)
Contrat externe 		✔ Le contrat externe Définit ce que l’API accepte et renvoie, sans exposer Mongo.
Controller (ItemsController)
Chef d’orchestre 		✔ Le chef d’orchestre Reçoit les DTO, applique les règles HTTP, appelle les services.
Service (ItemService)
Traducteur 		✔ Le traducteur Convertit DTO → Modèle → Mongo et inversement, reconstruit les URLs, applique la logique métier.
