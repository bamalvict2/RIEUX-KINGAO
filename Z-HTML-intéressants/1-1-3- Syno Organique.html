🛠️ 3. Tout doit être écrit quelque part

Architecture KING‑AO en trois groupes distincts, chacun clairement défini et versionné.

Les 3 groupes KING‑AO

EPARVIERS METIER (C#)
Groupe 1 – Métier
  • Code C# (.NET) métier
  • Image Docker eparvier-metier:latest
  • Scripts actions/metier/*.sh
  • Menu cockpit « EPARVIER METIER »
KINGDOMAINE (C#)
Groupe 2 – Domaine
  • Entités, agrégats, repositories
  • Image Docker kingdomaine:latest
  • Scripts actions/kingdomaine/*.sh
  • Menu cockpit « KINGDOMAINE »
KING‑AO Orchestrateur
Groupe 3 – Orchestration
  • Shell + Docker uniquement
  • Menus ACTIONS et cockpit
  • Scripts actions/orchestrator/*.sh
  • Pilotage des images et des logs
