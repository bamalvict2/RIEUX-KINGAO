Commandes terminal utiles pour vérifier emplacement et fichiers

Liste compacte des commandes à utiliser pour savoir où tu es, lister les fichiers, vérifier les dates et trouver des fichiers.

Chemin courant

CommandeUsage
pwd Affiche le chemin absolu du dossier courant. 
$ pwd
/home/bernard/EPARVIER/Stack-Solaize

Lister les fichiers

CommandeUsage
ls -la Liste tous les fichiers (y compris cachés) avec permissions et dates.
ls -lh --sort=time Liste lisible par taille et triée par date (les plus récents en haut). 
$ ls -la
drwxr-xr-x  6 bernard bernard 4.0K Apr 12 15:30 .
-rw-r--r--  1 bernard bernard 1.2K Apr 12 15:28 docker-compose.yml
-rw-r--r--  1 bernard bernard  512 Apr 12 15:20 README

Vérifier un fichier précis

CommandeUsage
stat nom_du_fichier Affiche date de modification, taille et autres métadonnées du fichier.
file nom_du_fichier Indique le type de fichier (texte, binaire, encodage). 
$ stat docker-compose.yml
  File: docker-compose.yml
  Size: 1234       Blocks: 8          IO Block: 4096 regular file
  Modify: 2026-04-12 15:28:10.000000000 +0200

Contrôle avec Git

CommandeUsage
git status Montre les fichiers modifiés/non commités dans le dépôt.
git diff nom_du_fichier Affiche les différences entre l'état modifié et la version committée. 
$ git status
On branch main
Changes not staged for commit:
  modified: docker-compose.yml

Trouver des fichiers

CommandeUsage
find . -name "docker-compose*.yml" Recherche des fichiers par nom dans le dossier courant et sous-dossiers.
grep -R "services:" . Recherche récursive par contenu (ici cherche la clé services:). 
$ find . -name "docker-compose*.yml"
./docker-compose.yml
./deploy/docker-compose.prod.yml

Utilitaires disque et tailles

CommandeUsage
du -sh * Affiche la taille de chaque élément du dossier courant (lisible).
find . -type f -size +50M -exec ls -lh {} \; Trouve les fichiers plus gros que 50 Mo et affiche leurs détails. 
$ du -sh *
4.0K    .git
1.2K    docker-compose.yml
120M    data

Vérifier si micro a sauvegardé

Si tu as fait Ctrl+S dans micro, le fichier est écrit sur disque. Pour confirmer la date de modification :

$ stat docker-compose.yml
Modify: 2026-04-12 15:28:10.000000000 +0200

Commande unique pratique

Copie-colle cette commande pour afficher en une fois le chemin courant, la liste et les 5 fichiers les plus récents :

pwd && echo && ls -lh --sort=time | head -n 10
